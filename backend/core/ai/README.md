# Core AI Layer

This layer acts as the foundation for all AI agents. It will contain:

- `memory/`: Handling conversation state and context.
- `embeddings/`: Utilities for text embeddings.
- `llm/`: Integration with LLM providers (OpenAI, Claude, etc).
- `vectorstore/`: Vector database interactions (Pinecone, PGVector, etc).
- `prompts/`: Core prompt management system.
- `tools/`: Shared tools for agents to use.
- `workflows/`: Standard LLM workflows.
